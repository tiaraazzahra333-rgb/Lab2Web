## Deskripsi
Praktikum ini membahas penggunaan HTML lanjutan untuk membuat halaman web, mulai dari tabel, formulir, validasi input, elemen semantik, hingga multimedia.

## Tujuan Praktikum
1. Memahami penggunaan tabel HTML.
2. Membuat formulir dengan berbagai jenis input.
3. Memahami validasi formulir.
4. Mengenal elemen semantik HTML.
5. Menambahkan audio dan video ke halaman web.
6. Membuat halaman biodata sederhana.

## Daftar Latihan
- Tabel data mahasiswa.
- Tabel menggunakan `thead`, `tbody`, `tfoot`, dan `colspan`.
- Formulir pendaftaran.
- Radio button dan checkbox.
- Select dan textarea.
- Validasi input.
- Semantic HTML.
- Penambahan audio dan video.
- Halaman biodata menggunakan `biodata.html`.
