## Deskripsi
Praktikum ini berisi latihan HTML lanjutan, mulai dari tabel, formulir, validasi input, elemen semantik, multimedia, sampai halaman biodata.

## Tujuan Praktikum
1. Memahami penggunaan tabel HTML.
2. Membuat formulir dengan berbagai jenis input.
3. Memahami validasi formulir.
4. Mengenal elemen semantik HTML.
5. Menambahkan audio dan video ke halaman web.
6. Membuat halaman biodata sederhana.
7. Mengunggah hasil praktikum ke GitHub.
